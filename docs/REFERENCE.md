# SciRust — Command and API Reference

Exhaustive operational reference for the workspace: every command, quality
gate, binary, cargo feature, and API entry point. The **exhaustive function
reference** is generated by rustdoc (see §8) — every public function is
documented from source.

Every command below ships with at least one working example. All examples are
real invocations; most are exercised by the test suite of `scirust-cli`
(`scirust-cli/src/lib.rs`), so they cannot silently rot.

> Toolchains: the repository pins **nightly** (rust-toolchain.toml) for the
> optional `portable-simd` and `nightly-simd` features. The default build has
> MSRV Rust **1.89** and **the whole workspace compiles and passes its tests on
> stable Rust** (CI job `build-test-stable`). The default build stays pure
> Rust, zero FFI, with no system dependency.

## 1. Quality gates (identical locally and in CI)

These are the exact commands run by `.github/workflows/ci.yml`. A change is
releasable only when all six pass:

| Gate | Command | Checks |
|---|---|---|
| Format | `cargo fmt --all -- --check` | workspace rustfmt style |
| Lints | `cargo clippy --workspace --all-targets -- -D warnings` | zero lints, code + tests + benches |
| Build | `cargo build --workspace --all-targets` | full compilation |
| Tests | `cargo test --workspace` | the entire suite |
| Multi-arch | `cargo +nightly-2026-07-02 check --workspace --all-targets --features scirust-simd/nightly-simd --locked --target aarch64-unknown-linux-gnu` | type-checks stable NEON and nightly SVE/SME/dotprod/i8mm paths (without executing them; run `rustup +nightly-2026-07-02 target add aarch64-unknown-linux-gnu` once) |
| Licenses/Security | `cargo deny check` | advisories, licenses, sources (`cargo install cargo-deny`) |

CI exports `RUSTFLAGS="-D warnings"`: every warning is an error.
`--all-features` is deliberately forbidden: `blas-openblas` and `blas-mkl` are
mutually exclusive `blas-src` backends.

## 2. The `scirust` unified CLI

```bash
cargo install --path scirust-cli   # provides the `scirust` binary
scirust help                       # lists every command below
```

A thin dispatcher over capabilities that already exist and are tested
elsewhere (it adds no new compute). Without installing:
`cargo run -p scirust-cli -- <command>`.

**Exit codes**: `0` success, `1` domain failure (fault/MISMATCH), `2` usage/IO.

**Determinism**: every command that accepts `--seed N` produces bit-identical
output for a given seed. Elapsed-time reporting goes to stderr on interactive
terminals only, so piped stdout stays byte-for-byte deterministic.

### 2.5 Numerical solvers

| Command | Description | Example |
|---|---|---|
| `integrate <expr> <a> <b> [var] [--method M]` | Definite integral (`romberg` \| `simpson` \| `gauss`). | `scirust integrate "x" 0 1` |
| `root <expr> <a> <b> [var] [--method M]` | A root in `[a,b]` (`brent` \| `bisection` \| `secant` \| `newton`). | `scirust root "x^2 - 2" 0 2` |
| `minimize <expr> <a> <b> [var]` | Local minimum in `[a,b]` (root of the symbolic derivative). | `scirust minimize "x^2 - 4*x + 7" 0 5` |
| `optimize <expr> --start a,b --vars x,y` | Multi-variable minimum via Nelder–Mead (derivative-free). | `scirust optimize "(x-1)^2 + (y-2)^2" --vars x,y --start 0,0` |
| `linsolve "r;r" "b"` | Solve `A·x = b` by LU (rows separated by `;`, coefficients by `,`). | `scirust linsolve "2,1;1,3" "3,5"` |
| `lstsq "r;r;r" "b"` | Least-squares `A·x ≈ b` via QR (rows ≥ cols). | `scirust lstsq "1,0;1,1;1,2" "1,2,3"` |
| `det "r;r"` | Determinant of a square matrix. | `scirust det "2,1;1,3"` |
| `cholesky "r;r"` | Cholesky factor `L` of an SPD matrix (`A = L·Lᵀ`). | `scirust cholesky "4,2;2,3"` |
| `qr "r;r"` | QR decomposition `A = Q·R` (prints Q and R). | `scirust qr "1,1;0,1;1,0"` |
| `cg "r;r" "b"` | Solve SPD `A·x = b` by conjugate gradient (iterative). | `scirust cg "4,1;1,3" "1,2"` |
| `inverse "r;r"` | Inverse of a square matrix (LU). | `scirust inverse "4,7;2,6"` |
| `solve-system "f1;f2" --vars x,y --start a,b` | Solve a nonlinear system `F(x)=0` (Broyden quasi-Newton). | `scirust solve-system "x^2 + y^2 - 4; x - y" --vars x,y --start 1,1` |
| `polyroots "c0,c1,.."` | Real roots of a polynomial (ascending coefficients). | `scirust polyroots "-2,0,1"` |
| `ode <f(t,y)> <y0> <t0> <t1> [h] [--method M]` | Integrate `dy/dt = f(t,y)` (`rk4` \| `dopri5` adaptive). | `scirust ode "y" 1 0 1`; `scirust ode "y" 1 0 1 --method dopri5` |
| `fem-heat <nodes> <length> <source>` | 1D steady heat `-u'' = source` via linear finite elements. | `scirust fem-heat 9 1 1` |
| `pinn [--seed N] [--steps S]` | Physics-informed NN: solves the BVP `u'' = -u` with the PDE residual in the loss; checked against `sin x`. | `scirust pinn --steps 50` |

Backed by: `scirust-solvers`, `scirust-symbolic` (expression parsing),
`scirust-core::nn::pinn`.

### 2.10 Inference integrity

| Command | Description | Example |
|---|---|---|
| `verify emit <model.qsr1> <out.proof> [batch] [seeds...]` | Seal a canonical `SCIRUST-PROOF-1` certificate (artifact sha256, resource certificate, FNV+sha256 output fingerprints over seeded inputs). Re-emission is bit-identical. | `scirust verify emit model.qsr1 model.proof 4 42 43` |
| `verify verify <bundle.proof> <model.qsr1>` | Re-derive everything from the bytes; exit `0` = MATCH, `1` = MISMATCH (any tampering of artifact or certificate is detected). | `scirust verify verify model.proof model.qsr1` |
| `certify [--seed N] [--eps E]` | Certify a ReLU MLP's output bounds over an L∞ box — IBP (layer-by-layer) and CROWN (tighter linear relaxation) side by side. | `scirust certify --eps 0.02` |

| `calibrate [--seed N]` | Temperature scaling: fit `T` to lower the expected calibration error (accuracy unchanged). | `scirust calibrate --seed 1` |
| `guard [--seed N] [--alpha A]` | Statistical guard: conformal Accept/Abstain/Reject verdicts with a distribution-free coverage guarantee. | `scirust guard --alpha 0.1` |
| `attest [--seed N]` | Hash-chained attestation log of verifiable inferences (Freivalds); verifies the chain, rejects a forged inference, tamper-evident. | `scirust attest --seed 42` |

Backed by: `scirust_runtime::proofcli`, `scirust-core::nn::{ibp, conformal,

## 4. Auxiliary binaries

### 4.1 `som-analyze` / `cargo som` — ownership linter for CI

```bash
cargo install --path scirust-som/crates/cli   # installs som-analyze + cargo-som
cargo som --sarif src/lib.rs > som.sarif       # SARIF 2.1.0 (code scanning)
som-analyze path/to/file.rs                    # same engine as `scirust analyze`
```

Parses the file with the real Rust grammar (`syn`), runs the deterministic
ownership oracle, prints the per-token table (ownership/borrow/fault) and
diagnostics. Documented limitation: file-level locations (line-precise
regions arrive with frontend spans). Examples provided:
`scirust-som/examples/*.rs`.

### 4.2 `scirust-verify` — verifiable inference certificates

```bash
cargo run -p scirust-runtime --bin scirust_verify -- emit   model.qsr1 model.proof [batch] [seeds...]
cargo run -p scirust-runtime --bin scirust_verify -- verify model.proof model.qsr1
```

Same engine as `scirust verify` (§2.10), exposed as a standalone binary.

### 4.3 `openclaw-u` — autonomous agent demo (outside the framework)

```bash
cargo run --features openclaw --bin openclaw-u
```

### 4.4 Runtime audit binaries (`scirust-runtime/src/bin/`)

## 6. Cargo features

| Crate | Feature | Effect |
|---|---|---|
| scirust-core | `rayon` *(default)* | CPU data parallelism |
| scirust-core / scirust-simd | `portable-simd` | kernels and generic `std::simd` API (nightly; the `scirust-core` feature activates the `scirust-simd` one) |
| scirust-simd | `nightly-simd` | AMX on x86_64; SVE/SME, dotprod and i8mm on AArch64 (pinned nightly, architecture-selected paths) |
| scirust-core | `blas-openblas` / `blas-mkl` | matmul via system BLAS — mutually exclusive, require the system toolchain |
| scirust-gpu | `wgpu` / `cuda` | Real opt-in backends: portable WGSL compute via wgpu, or CUDA bf16/cuBLASLt GEMM with fp32 accumulation |
| scirust (root) | `tensor-canonical[-cpu\|-wgpu\|-cuda]` | Canonical tensor facade, backend-free by default; adapters are opt-in |

## 7. Crate map (entry points)

| Crate | Role | Main entry |
|---|---|---|
| `scirust` (root) | facade `scirust::{core,simd,symbolic,learning,solvers}` | `src/lib.rs` |
| `scirust-core` | 2D tensor, autodiff tape, NN layers, int8 quantization, data, AMP/DP/pruning/distributed | `autodiff::reverse::{Tape,Tensor,Var}`, `nn::*` |
| `scirust-simd` | AVX2/SSE2/NEON kernels + runtime dispatch | `dispatch::runtime_backend()` |
| `scirust-runtime` | deterministic SRT1 inference + manifest | `lib.rs` + audit bins |
| `scirust-solvers` | linalg, solvers | `linalg::*` |
| `scirust-learning` | optim/control/NLP pipeline | `nlp::sentiment` |
| `scirust-symbolic` | symbolic differentiation | `lib.rs` |
| `scirust-neuro-symbolic` | datalog, CSP, SAT/SMT, KG, probabilistic | `Reasoner` |
| `scirust-evo` | seeded GA / CMA-ES / OpenES / NSGA-II | `GeneticAlgorithm`, `Nsga2` |
| `scirust-tn` | Tensor-Train (re-exports `core::tn`) | `TTLinear` |
| `scirust-signal` | FFT, features, radar, **denoising** (7 families + auto/tournament/cascade + streaming) | `denoise::{denoise_auto, denoise_best, denoise_cascade}` |
| `scirust-vision` | EO/IR optronics + **2-D denoising** (median, separable wavelets, NLM) | `denoise::{median2d, wavelet_denoise2d_auto, nlm2d}` |

For the authoritative workspace inventory (150+ crates), run
`cargo metadata --no-deps`.

## 8. Exhaustive function documentation (rustdoc)

```bash
cargo doc --workspace --no-deps --open
```

Generates the complete reference of **every public function** in the
workspace, from code comments (the only source that cannot drift from the
code). The rustdoc is the authoritative function documentation; this file is
its operational index.
